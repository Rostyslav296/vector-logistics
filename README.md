# Vector Logistics

The website for Vector Logistics, a Tennessee-based, American-owned truck dispatching service.
Plain HTML and CSS, published with GitHub Pages (`.nojekyll`: served as it is, no Jekyll build).

- `index.html`: Home (services, local and American, pricing, how it works, FAQ)
- `about.html`: About Rusty
- `contact.html`: the contact and sign-up form (Web3Forms)
- `css/styles.css`, `js/main.js` (the menu and the form)
- `images/`: the logo (`logo.png`, `logo-white.png`, the mark and the wordmark, the icons) and the photos

The three pages are generated by `tools/build_site.py` from one header and footer: edit the text
there and run `python3 tools/build_site.py`.

**The contact form** posts to Web3Forms. Until its access key is in place (the
`WEB3FORMS_ACCESS_KEY` placeholder in `tools/build_site.py`), the form tells visitors to call or
email instead of sending. The key is made to be public, so it can live in the page.

The fee and the contact details follow the company manifest in the Rostyslav app's Vector
Logistics page.
