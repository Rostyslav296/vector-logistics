# Vector Logistics

The website for Vector Logistics, a truck dispatching service. Plain HTML and CSS, published with GitHub Pages
(`.nojekyll`: served as it is, no Jekyll build).

- `index.html`: Home
- `about.html`: About
- `images/`: the logo (`logo.svg`) and AI-generated pictures

The fee and the contact details on the pages follow the company manifest in the Rostyslav app's
Vector Logistics page.
